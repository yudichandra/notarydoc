Pengaturan Aplikasi & Direktori Berkas

Kelola konfigurasi identitas kantor notaris default dan folder penyimpanan berkas. Pengaturan ini tersimpan secara lokal dan otomatis diterapkan pada pembuatan akta.

⚖️

1. Profil Kantor Notaris Default

Simpan nama dan gelar notaris Anda agar otomatis terisi pada setiap draf akta baru tanpa perlu mengetik ulang.

Ditulis kapital/huruf besar tanpa koma gelar
Wilayah yurisdiksi kedudukan kantor notaris
Digunakan pada narasi komparisi penghadapan awal akta

✓ Profil kantor berhasil disimpan!
📁

2. Direktori Folder Penyimpanan Berkas

Tentukan lokasi folder tempat seluruh berkas draf (.akta) dan hasil dokumen Word (.docx) diarsipkan secara terpusat di komputer Anda. Jika belum diatur, Windows File Explorer akan otomatis meminta pemilihan folder saat pertama kali Anda menyimpan draf atau mengekspor dokumen.

Lokasi penyimpanan terpadu untuk berkas progres (.akta) dan hasil dokumen Word (.docx)
